## 📚 How jarl works

jarl uses a simple result style. That means your code can return either:

- A success value
- An error value

This helps you check what happened without guessing. It also keeps the code in one clear path.

A common pattern looks like this:

- Run a task
- Check if it worked
- Read the success value if it did
- Read the error if it did not

This is useful for:

- File work
- Network calls
- Form checks
- Data parsing
- Any task that can fail
